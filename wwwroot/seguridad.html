¿Está lista para producción?

Subí el código de la aplicación y, si lo tenés, el documento del asesor de arquitectura. El revisor corre chequeos automáticos, lee el código y entrega hallazgos con evidencia y un veredicto según el perfil de seguridad de IT.

Obligatorio Código (.zip)
Sin node_modules, bin, obj ni .env. Hasta 30 MB.
Opcional Documento de arquitectura
.docx, .md, .txt o .json del asesor de plataforma.

No cargues secretos reales: el código se envía al modelo de IA para su revisión y no se guarda en el servidor.
